# liam-play-content

Public content feed for a toddler's play curriculum (web game).
Content-only repo: activity definitions, audio, video, images.

Security policy: this repo must NEVER contain secrets, API keys, passwords,
tokens, credentials, or personal data beyond a first name. Everything here is
public by design (it is served to a public web page). Do not commit anything
that is not meant for the public internet.
